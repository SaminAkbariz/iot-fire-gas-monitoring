# 🌐 سیستم مانیتورینگ IoT (تشخیص آتش، گاز، دما و رطوبت)

پروژه دانشگاهی سیستم هوشمند پایش محیطی مبتنی بر IoT با استفاده از برد **ESP32** و سنسورهای آتش، گاز (MQ2) و دما/رطوبت (DHT22). داده‌های سنسورها به یک بک‌اند **Django** ارسال می‌شود، در داشبورد وب نمایش داده می‌شود و در صورت تشخیص خطر، هشدار ایمیلی برای کاربر ارسال و بازر (buzzer) فعال می‌شود.

## ✨ امکانات

- 📡 دریافت آنی داده از ESP32 از طریق HTTP API
- 🔥 تشخیص آتش، گاز/دود، دمای بالا و رطوبت غیرعادی
- 🚨 فعال‌سازی خودکار بازر هنگام خطر + امکان قطع دستی توسط کاربر
- 📧 ارسال ایمیل هشدار به صاحب دستگاه (SMTP Gmail)
- 👤 سیستم ثبت‌نام و ورود کاربران (احراز هویت سفارشی)
- 📊 داشبورد وب زنده برای مشاهده وضعیت سنسورها

## 🛠 تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| بک‌اند | Django 6.0 |
| دیتابیس | SQLite |
| فرانت‌اند | HTML, CSS, JavaScript, Bootstrap 5 |

## 📁 ساختار پروژه

```
├── accounts/           # اپلیکیشن کاربران (ثبت‌نام، ورود، پروفایل)
├── devices/             # اپلیکیشن دستگاه‌ها (دریافت داده سنسور، هشدارها، بازر)
├── config/               # تنظیمات اصلی پروژه Django
├── static/               # فایل‌های CSS و JS داشبورد
├── templates/            # قالب HTML داشبورد
├── hardware/
│   └── esp32_firmware.ino   # کد فریمور ESP32 (Arduino)
├── requirements.txt
├── .env.example          # نمونه متغیرهای محیطی
└── manage.py
```

## 🚀 راه‌اندازی پروژه (بک‌اند وب)

### ۱. کلون کردن پروژه

```bash
git clone <آدرس ریپازیتوری شما>
cd <نام پوشه پروژه>
```

### ۲. ساخت محیط مجازی و نصب پکیج‌ها

```bash
python -m venv venv

# ویندوز
venv\Scripts\activate

# مک / لینوکس
source venv/bin/activate

pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی

فایل نمونه را کپی کن و مقادیر خودت را وارد کن:

```bash
cp .env.example .env
```

سپس فایل `.env` را باز کن و مقادیر زیر را با اطلاعات خودت پر کن:

- `SECRET_KEY` — یک رشته تصادفی برای امنیت جنگو
- `EMAIL_HOST_USER` و `EMAIL_HOST_PASSWORD` — برای ارسال ایمیل هشدار (نیازمند [App Password جیمیل](https://myaccount.google.com/apppasswords))

> ⚠️ فایل `.env` حاوی اطلاعات محرمانه است و در `.gitignore` قرار دارد؛ هرگز آن را commit نکن.

### ۴. اجرای migration ها

```bash
python manage.py migrate
```

### ۵. ساخت کاربر ادمین (اختیاری)

```bash
python manage.py createsuperuser
```

### ۶. اجرای سرور

```bash
python manage.py runserver 0.0.0.0:8000
```

داشبورد در آدرس `http://127.0.0.1:8000` در دسترس است.

## 🔌 راه‌اندازی سخت‌افزار (ESP32)

1. فایل `hardware/esp32_firmware.ino` را با **Arduino IDE** باز کن.
2. کتابخانه‌های مورد نیاز را نصب کن: `ArduinoJson`, `DHT sensor library`.
3. مقادیر زیر را در ابتدای فایل با اطلاعات خودت جایگزین کن:
   - `ssid` و `password` → نام و رمز وای‌فای خودت
   - `serverUrl` → آدرس IP سیستمی که سرور جنگو روی آن اجرا می‌شود (باید در همان شبکه محلی باشد)
4. کد را روی ESP32 آپلود کن.

### اتصال سنسورها به پین‌ها

| سنسور | پین |
|---|---|
| MQ2 (گاز) | GPIO 34 |
| Flame (آتش) | GPIO 35 |
| DHT22 (دما/رطوبت) | GPIO 32 |
| Buzzer | GPIO 25 |
| LED | GPIO 26 |

## 📡 API Endpoints

| متد | مسیر | توضیح |
|---|---|---|
| POST | `/devices/data/` | دریافت داده سنسور از ESP32 |
| GET | `/devices/data/?all=1` | دریافت ۵۰ رکورد آخر |
| GET | `/devices/data/all/` | دریافت ۱۰۰ رکورد آخر |
| POST | `/devices/buzzer/` | روشن/خاموش کردن دستی بازر |
| GET | `/devices/buzzer/status/` | دریافت وضعیت بازر توسط ESP32 |
| POST | `/accounts/register/` | ثبت‌نام کاربر |
| POST | `/accounts/login/` | ورود کاربر |
| POST | `/accounts/logout/` | خروج کاربر |
| GET | `/accounts/me/` | اطلاعات کاربر لاگین‌شده |
